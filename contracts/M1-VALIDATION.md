# M1 검증 메모

2026-11-07에 구현한 Node GitHub 클라이언트로 토큰 없이 공개 API를 직접 확인했다. 아래 개수는 해당 응답 시점의 관측값이며 고정 기대값으로 실시간 테스트하지 않는다.

| 리소스 | 응답 본문 | Link의 last | 조건부 재조회 |
| --- | --- | --- | --- |
| octocat/Hello-World 열린 PR, per_page=1 | 1개 | 1374 | 304 |
| nodejs/node 커밋, since=2026-10-08T00:00:00Z, per_page=1 | 1개 | 422 | 304 |

Link 경로는 요청의 `/repos/owner/name` 대신 `/repositories/<숫자 ID>`로 반환됐다. 집계와 워크플로 페이지 처리 모두 확인한 동일 저장소 ID의 정규 경로를 지원한다. 회귀 테스트에는 토큰·실제 이슈 내용 없이 이 Link 형태만 기록했다.

자동 테스트는 세션 격리, 암호화·변조 거부, 로그아웃 쿠키 무효화, 연결 중 해제 경합, 304 집계 유지, 이동하는 30일 창, PR 제외, 0 활동 비율, 추가 워크플로 실패, 페이지 처리, 예산 부족과 stale, 해제 후 폴링 중단을 검증한다. HTTP 통합은 로컬 가짜 GitHub 서버로 실행한다.

실제 PAT/비공개 저장소 연동과 S3 화면은 이 환경에서 검증하지 않았다. M2 통합 시 사용자 자격증명으로 별도 검증해야 한다. M1에는 Device Flow, GitHub 이벤트 생성, status.json 어댑터, SSE, manifest, 웹훅이 포함되지 않는다.
