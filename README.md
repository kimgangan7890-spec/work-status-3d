# work-status-3d

AI 에이전트들의 작업 현황을 3D 사무실로 보여 주는 화면이에요(팀 최대 8개, 에이전트 최대 24명). 책상에 앉은 에이전트의 상태(일하는 중, 대기, 막힘)가 모니터 색과 자세로 보이고, 문서가 화이트보드로 날아가면 오른쪽 메인 보드의 해당 작업 행이 번쩍여요. 폰(폭 390px)에서도 읽을 수 있게 만들었어요.

- 보드에는 에이전트 카드, PRD·BP·MVP 항목, 진행도 3종(PRD 확정·MVP 구현·전체 작업), 구역별 작업과 진행률이 나와요.
- 서버 모드에서는 로그인한 뒤 화면에서 개인 지시(한 명에게)와 공동 지시(모두에게)를 보낼 수 있어요. 지시는 파일에 쌓일 뿐 자동으로 실행되지 않아요.
- 공개판은 팀 3개짜리 샘플 데이터만 보여 주고(층 화면이 첫 화면), 로그인과 지시 기능이 없어요. **내 데이터 불러오기**로 내 파일 두 개를 고르면 내 브라우저 안에서만 읽어요.

- 프로젝트가 여럿이면 `projects.json`에 GitHub 저장소를 적어 프로젝트마다 사무동을 만들 수 있어요(공개 저장소는 바로, 비공개는 서버 모드에서 읽기 전용 토큰으로). `ADOPT.md`의 "여러 프로젝트" 참고.

프로젝트가 2개 이상이고 캔버스 폭이 600px 이상이면 밝은 외벽·세로 창·옥탑을 가진 3D 사무동 단지를 먼저 보여 줘요. 건물·이름표·카드로 사무동에 들어가고 **← 단지**로 돌아와요. 폰은 기존 프로젝트 카드를 사용해요.

## 빠르게 써 보기
Node.js가 필요해요(빌드는 20.19 이상 또는 22.12 이상, 테스트는 22.12 이상).

```bash
npm ci
npm test
npm run dev
```

브라우저에서 `http://127.0.0.1:5174`를 열면 개발용 화면이 보여요. 데이터는 `public/status.json`, `public/board.json`이에요.

## 서버 모드로 켜기
```bash
npm run build
DASH_PASSWORD=내암호 npm start
```

`http://127.0.0.1:5180`에서 열려요(이 컴퓨터에서만). 암호는 **환경 변수로만** 넣고 파일이나 코드에 적지 마세요. 암호가 없으면 서버가 켜지지 않아요. Windows PowerShell은 `$env:DASH_PASSWORD="내암호"; npm start`예요.

## 공개판 만들기
```bash
npm run release:public
```
샘플 데이터 생성, 공개용 빌드(`dist-public`), 개인정보·내부 경로·키 검사를 한꺼번에 해요. 검사를 통과한 결과만 올리세요.

## 문서
- `ADOPT.md`: 내 데이터로 도입하는 방법(공개판 화면만 쓰기, 서버 모드, 내 프로젝트에 이식)과 오류 문구 안내예요.
- `DATA.md`: `status.json`, `board.json` 형식과 지시 API 계약이에요.
- 팀이 2개 이상이면 팀마다 방이 생기는 층 전체 화면이 나와요(`ADOPT.md`의 "팀 방 나누기").

## 폴더 구조
- `src/scene/`: 3D 사무실 장면과 데이터 읽기(`store.js`).
- `src/panels/`: 오른쪽 메인 보드, 이벤트 로그, 지시 입력, 내 데이터 불러오기.
- `src/shared/`: 파일 검사(`validate.js`)와 키·토큰 모양 검사 등 공용 코드.
- `server.js`: 로그인과 지시 API를 제공하는 서버(서버 모드 전용).
- `update.js`: 현황 파일을 안전하게 고치는 명령줄 도구(`node update.js help`).
- `scripts/`: 샘플 생성과 공개 검사 스크립트.
- `test/`: 테스트.

## 주의
