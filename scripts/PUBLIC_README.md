# 작업현황 3D (공개 샘플)

AI 에이전트 3명의 작업 현황을 3D 사무실로 보여 주는 화면이에요. 책상에서 문서가 메인 보드로 날아가고, 보드 막대가 진행률만큼 채워져요. 게시판에는 MVP 요약과 구역별 담당·진행률이 나와요. 폰(폭 390px)에서도 볼 수 있어요.

- 이 저장소의 화면은 **샘플 데이터**만 보여 줘요. 가짜 이름과 가짜 작업뿐이에요.
- 공개판에는 로그인도 작업 지시 기능도 없어요. 서버 호출 코드가 빌드에서 빠져 있어요.
- **내 데이터 불러오기**로 내 `status.json`, `board.json`을 고르면 내 브라우저 안에서만 읽어 보여 줘요. 서버로 올라가지 않고 새로고침하면 샘플로 돌아가요.

## 구성
- `index.html`, `assets/`, `status.json`, `board.json`: 화면 파일과 샘플 데이터예요. 정적 파일이라 어떤 정적 호스팅에든 올릴 수 있어요. 경로가 상대 경로라서 하위 주소에서도 동작해요.
- `ADOPT.md`: 내 작업에 적용하는 방법이에요.

## 로컬에서 열어 보기
```bash
python3 -m http.server 8080
```
이 폴더에서 위 명령을 실행하고 브라우저에서 `http://127.0.0.1:8080`을 열어요. 파일을 더블클릭해 여는 방식은 브라우저가 데이터 읽기를 막아서 안 돼요.
